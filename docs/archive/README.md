# Arquivo histórico

Documentos de escopo/planejamento de PRs já mesclados, planos pontuais já
executados, e recaps de sessão — mantidos aqui por valor histórico (entender
uma decisão passada), fora da navegação do dia a dia e do contexto que a IA
carrega por padrão.

Não é lixo: `git log --follow` em qualquer arquivo aqui mostra o histórico
completo de antes da mudança de pasta. Se algo aqui contradiz o código atual,
o código manda — nada neste diretório é atualizado depois de arquivado.

Auditoria original: 2026-08-25, classificação em `docs/BACKLOG-PENDENCIAS.md`
não se aplica — ver commit que criou esta pasta para o critério usado
(histórico de PR concluído, par -escopo.md redundante com -escopo-implementavel.md,
ou conteúdo desatualizado que já indicava seu próprio substituto).
